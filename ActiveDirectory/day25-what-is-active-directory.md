# Day 25 - What is Active Directory

## Key Concepts
Active Directory (AD) is a directory service developed by Microsoft for Windows domain networks. It acts as a central database that stores information about users, computers, and other resources, allowing IT administrators to manage access and permissions centrally.

## Lab
- Reviewed the concept of a Domain vs. a Workgroup.
- Explored the Server Manager dashboard to see how AD DS (Active Directory Domain Services) integrates with Windows Server.

## Why It Matters
Without AD, an IT team would have to create user accounts on every single computer. AD allows a user to log into any domain-joined computer with a single set of credentials. Every major enterprise uses AD.

## Interview Q&A
**Q: What problem does Active Directory solve?**
A: It solves the problem of decentralized management. Instead of managing every PC individually, AD provides a single, centralized location to manage users, computers, and security policies.
