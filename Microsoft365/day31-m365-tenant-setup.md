# Day 31 - Microsoft 365 Tenant Setup & Admin Center

## Key Concepts
The Microsoft 365 Admin Center is the cloud dashboard for managing users, licenses, and services. To practice these enterprise skills without paying for a full subscription, Microsoft offers a 30-day free trial of Microsoft 365 Business Basic. 

## Lab
- Signed up for a free 30-day Microsoft 365 Business Basic trial.
- Set up a custom tenant domain.
- Configured Multi-Factor Authentication (MFA) using the Microsoft Authenticator app for the admin account (mandatory for new tenants).
- Explored the Admin Center dashboard (Users, Teams, Billing).

## Why It Matters
MFA is the first line of defense in cloud security. As an L1 tech, you will frequently walk users through MFA setup and troubleshoot login issues.

## Interview Q&A
**Q: Why is MFA important for admin accounts?**
A: Admin accounts have the power to delete users, change billing, and alter security policies. MFA ensures that even if a password is stolen, the attacker cannot log in without the second factor.
